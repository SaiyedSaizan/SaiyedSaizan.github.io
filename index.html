Agent Governance Runtime — read the case study

Policy and audit layer for AI agents. It evaluates every tool call against deterministic policy before execution, and records each decision in a hash-linked log that an offline verifier can re-derive without trusting the runtime that wrote it.

The decision core has no LLM or network imports — a test reads the source and fails the build if one appears. The case study has a working verifier you can tamper with.

03

AI Watch — Watch-Aware Tutor — read the case study

A Chrome extension that answers questions about the video you're watching and cites only the parts you have actually watched. Watched time is accumulated from a 250 ms sampler, and citations are re-checked against it server-side, so the model can't point at something you haven't reached.

The hard part was identity, not prompting: the page can navigate to a different video during any of five awaits, and the in-flight request must not answer with the wrong transcript.

TypeScript · Chrome MV3 · Express · 149 tests

Motor-ID assignment, serial communication, controller configuration, teleoperation, and checking that depth frames were actually recorded rather than silently dropped — the work that decides whether any of the learning is possible.
